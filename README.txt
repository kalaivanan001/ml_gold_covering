ML GOLD COVERING — STATIC WEBSITE
=================================

Files
-----
index.html  Main English-language website content
style.css   Responsive design, colours, backgrounds and layout
script.js   Small client-side interactions only (mobile menu and copyright year)

How to preview
--------------
1. Extract this folder from the ZIP file.
2. Double-click index.html to open it in a browser.
3. Internet access is needed for the remote jewellery photos and Google Fonts.

Static website details
----------------------
This is a static informational website. It does not use a database, server,
admin panel, customer login, shopping cart, payment system or order database.
The JavaScript is only used for the mobile navigation and current copyright year.

Before publishing
-----------------
1. In index.html, replace +91 XXXXX XXXXX with the real shop phone number.
2. Replace https://wa.me/91XXXXXXXXXX with the WhatsApp URL for the shop.
   Use country code plus number, digits only, with no plus sign or spaces.
3. Replace the phone link tel:+91XXXXXXXXXX with the actual phone number.
4. Add the complete shop address and actual opening hours.
5. Replace the generic Instagram, Facebook and YouTube links with the shop's
   own social media profile links.
6. The jewellery photos are illustrative. Replace them with your own product
   photographs and verify permission/usage rights before publishing.
7. Upload index.html, style.css and script.js to your static hosting provider.

Design
------
Deep emerald green, antique gold and warm ivory theme, decorative background
pattern, responsive layout, collection cards plus an expanded eight-image gallery, about section,
service highlights, contact section, social icons and copyright footer.
